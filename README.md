# Phishing Awareness Program

## Project Overview

This project is a cybersecurity awareness presentation designed to educate users about phishing attacks, their warning signs, and ways to prevent them.

## Objectives

* Understand phishing and how it works.
* Identify different types of phishing attacks.
* Recognize suspicious messages, links, and fake login pages.
* Learn safe online practices and account protection methods.
* Understand what to do after clicking a phishing link.

## Topics Covered

* Introduction to phishing
* Types of phishing
* Social engineering techniques
* Identifying phishing emails
* Fake login pages and fraudulent websites
* Fake KYC message case study
* Prevention and protection methods
* Response to phishing incidents
* Cybersecurity awareness quiz
